# CodeKeeper

CodeKeeper is a **mobile-first 60-day coding challenge experience** designed for Indian students who build consistently and maintain a public proof of work through **GitHub commits and LinkedIn posts**.

Built for the ABTalks design challenge.

---

## ✨ Key Idea

Most students lose motivation when they miss a single day.

CodeKeeper introduces **Streak Recovery**:

- 🔥 3 recovery credits per month
- 🧠 20-minute skill quiz to restore a missed day
- 📈 Focus on habit formation, not punishment
